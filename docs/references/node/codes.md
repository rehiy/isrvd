# 注册码 API

> 受管机凭注册码向中控注册；界面上未使用的注册码与节点显示在同一个列表里，状态为「待接入」。仅在 `isrvd --mode center`（中控）下可用，**仅创始人可调用**，接口由网关提供，不在 isrvd 的 `/api/*` 路由表中。节点管理见 [受管节点](nodes.md)，部署与接入流程见 [集中管理](../../multi-node.md)。
>
> 注册码**只能使用一次**，默认 60 分钟过期，最长 7 天；用 `server.jwtSecret` 派生的密钥**加密保存**，待接入期间可随时查看（见下），使用后立即删除；修改 `jwtSecret` 后未使用的注册码会被清除。数据保存在业务数据存储的 `node-code.yml`（配置位于 etcd 时改存 `<配置 key>/node-code.yml`）。

---

### 查询注册码列表

```bash
isrvd_get "/node/codes"
```

只列出尚未使用且未过期的注册码，过期的会在查询时清理。

**响应字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 注册码 ID（UUID，只读） |
| `code` | string | 注册码明文（落盘为密文，仅此接口解密返回） |
| `name` | string | 备注 |
| `autoApprove` | bool | 使用该码注册的节点是否自动审批 |
| `createdBy` | string | 创建人 |
| `createdAt` | string | 创建时间 |
| `expiresAt` | string | 过期时间 |

> `code` 为注册码明文，仅创始人可读；界面上点击「查看接入命令」即可得到完整的受管机启动命令。注册码使用一次后或过期后即被删除，不再返回。

### 生成注册码

```bash
isrvd_post "/node/code" '{
  "name": "杭州机房 web-01",
  "ttlMinutes": 60,
  "autoApprove": false
}'
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 备注，可选，最长 64 个字符 |
| `ttlMinutes` | number | 有效期（分钟）；`0` 或不填为 60，超过 10080 按 10080 处理 |
| `autoApprove` | bool | `true` 时节点注册后无需人工审批，直接上线；仅建议在可信网络内使用 |

**响应：** 与列表项字段相同，含 `code`。

受管机使用方式：

```bash
isrvd --mode agent --center-url https://center.example.com --enroll-code <code>
```

### 撤销注册码

```bash
isrvd_delete "/node/code/<ID>"
```

撤销后尚未使用该码接入的受管机无法注册；已经完成注册的节点不受影响。

---

## 注册码在受管机侧的行为

- 首次注册成功后，节点令牌加密保存在受管机本地，之后重启**无需**再带注册码。
- 注册码长期留在启动参数或环境变量里是安全的：本地已有可用凭据时不会再使用它。
- 中控拒绝本地令牌（节点被吊销、删除，或中控数据被重置）时：
  - 若启动时给了注册码且尚未用过，会用它重新注册，**成功后才替换**本地凭据；
  - 否则保留本地凭据，每分钟重试并记录错误日志。中控数据恢复后会自动重连，不需要人工处理。
