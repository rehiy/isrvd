# 注册码 API

> 受管机凭注册码（即节点令牌）连接中控；界面上未使用的注册码与节点显示在同一个列表里，状态为「待接入」。仅在 `ISRVD_MODE=center`（中控）下可用，**需要对应的节点路由权限**，接口由网关提供，权限元信息在中控 `GET /account/routes` 中列出。节点管理见 [受管节点](nodes.md)，部署与接入流程见 [集中管理](../../multi-node.md)。
>
> 注册码即节点令牌，**激活前有效期有限**，默认 60 分钟过期，最长 7 天；用 `server.jwtSecret` 派生的密钥**加密保存**，待接入期间可随时查看（见下），首次连接激活为节点后删除；修改 `jwtSecret` 后未使用的注册码会被清除。数据保存在业务数据存储的 `node-code.yml`（配置位于 etcd 时使用 `<配置 key>/node-code.yml`）。

---

### 查询注册码列表

```bash
isrvd_get "/node/codes"
```

只列出尚未使用且未过期的注册码，过期的会在查询时清理。

**响应字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 注册码 ID（UUID，只读） |
| `code` | string | 注册码明文（落盘为密文，仅此接口解密返回） |
| `name` | string | 备注 |
| `createdBy` | string | 创建人 |
| `createdAt` | string | 创建时间 |
| `expiresAt` | string | 过期时间 |

> `code` 为注册码明文，仅拥有 `GET /api/node/codes` 权限的成员可读（创始人默认可读）；界面上点击「查看接入命令」即可得到完整的受管机启动命令。注册码列表仅包含尚未使用且在有效期内的条目。

### 生成注册码

```bash
isrvd_post "/node/code" '{
  "name": "杭州机房 web-01",
  "ttlMinutes": 60
}'
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 备注，可选，最长 64 个字符；非空时作为接入节点的名称，优先于受管机上报的名称 |
| `ttlMinutes` | number | 有效期（分钟）；`0` 或不填为 60，超过 10080 按 10080 处理 |

**响应：** 与列表项字段相同，含 `code`。

受管机使用方式：

在受控机启动环境中设置以下变量，然后启动或重启服务：

```bash
export ISRVD_MODE=agent
export ISRVD_CENTER_URL=https://center.example.com
export ISRVD_NODE_TOKEN="<code>"
isrvd
```

### 撤销注册码

```bash
isrvd_delete "/node/code/<ID>"
```

撤销后尚未使用该令牌接入的受管机无法连接；已经接入的节点不受影响。

## 注册码在受管机侧的行为

- 界面上的「注册码」就是节点令牌（`<节点ID>.<密钥>`），受控机从环境变量 `ISRVD_NODE_TOKEN` 读取并直接连接中控。同一 token 已在线或握手中时返回 `409`，不会顶替已有连接。
- 首次连接成功时，中控把待接入记录激活为节点（保留令牌哈希）并删除该记录；之后同一令牌继续有效，直到节点被吊销或删除。
- 令牌在激活前过期（默认 60 分钟，最长 7 天）则无法连接，需重新生成。
- 中控拒绝令牌（节点被吊销、删除、令牌过期未激活，或中控数据被重置）时，受管机每分钟重试并记录错误日志；中控数据恢复后会自动重连。
