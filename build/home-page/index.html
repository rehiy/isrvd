快速开始

一条命令即可安装，或按需选择部署方式、集成组件、软件源与运行角色

bash — 一键安装（推荐） 复制
bash <(curl -sL https://isrvd.rehiy.com/install/) install

安装 systemd 服务，自动按 IP 选择下载源；装完访问 http://服务器IP:8080，默认账号 admin / admin

    管理命令

    update 自动识别二进制或 Docker 部署；uninstall 删除容器与二进制但保留数据目录
    bash复制
    高级：直接运行与配置来源（本地 YAML / etcd）
    bash — 直接运行复制
    # 默认读取 ./config.yml ./isrvd # 本地 YAML ISRVD_CONFIG=/data/conf/isrvd.yml ./isrvd # etcd 配置（value 为 YAML 格式） ISRVD_CONFIG="etcd://user:pass@127.0.0.1:2379/isrvd/config?scheme=http&timeout=5s" ./isrvd # etcd key 不存在时，用 fallback YAML 初始化并写入 etcd ISRVD_CONFIG="etcd://127.0.0.1:2379/isrvd/config?fallback=/data/conf/isrvd.yml" ./isrvd

    etcd 认证可省略或用 ETCD_USERNAME / ETCD_PASSWORD 补充；详见 README「配置」章节

    集中管理

    同一个二进制，一个控制台管理多台服务器

    浏览器
    →
    isrvd --mode center
    ⇄
    隧道
    ⇠
    isrvd --mode agent
    × N 台

    隧道由受管机主动发起，中控从不主动外连；受管机位于 NAT 或防火墙后也可以接入

    一个二进制，三种角色

    --mode 选择 server（默认单机）、center（中控）或 agent（受管机），无需额外程序，默认配置文件无需改动

    切换节点即切换视角

    在页头选择节点，Docker、Swarm、Compose、文件、终端、计划任务、APISIX、Caddy 与系统概览都作用于该节点，含实时日志与大文件传输

    账号与权限统一在中控

    成员、权限、系统配置和 AI 助手只维护一份；单机用户看不到任何节点界面，升级后行为不变

    接入可控，随时吊销

    一次性注册码自动接入、仅创始人可操作；节点令牌只存哈希，待接入的注册码可随时查看，吊销后立即断开

    首次注册后凭据加密保存在受管机本地，重启无需再带注册码；受管机与中控的版本需一致。详见 集中管理文档

    部署中控或受管机

    在快速开始中将「运行角色」切换为中控或受管机，即会生成对应的启动命令——中控只需一个环境变量；受管机可填入中控地址与注册码，自动生成即复即用的接入命令。

    分层架构，高内聚低耦合

    config
    →
    registry
    →
    pkgs
    →
    service
    →
    server

    config

    配置加载（YAML/etcd）

    registry

    外部服务初始化与可用性检查

    pkgs

    各模块客户端（Docker / Swarm / APISIX / Caddy / GPU / SSH）

    service

    业务逻辑、类型转换、权限校验

    server

    HTTP handlers、路由注册、中间件

    webview

    Vue 3 前端（Pinia + TypeScript + Tailwind CSS）

    设计原则：高内聚（同领域功能聚合）、低耦合（层间通过接口解耦）、单一职责（Handler 只管 HTTP）
